Overview

Gunakan nama unik sepanjang 2–40 karakter, terdiri dari huruf, angka, atau tanda hubung. Region yang tersedia: Jakarta, Singapore, dan Tokyo. Ukuran Starter, Professional, dan Business menentukan alokasi CPU/RAM serta estimasi biaya. Stop mempertahankan resource dalam daftar; Delete menghapusnya setelah konfirmasi.

Command reference

skyforge instances list

Yang perlu diketahui

Seluruh tindakan pada prototype berjalan lokal di browser. Tidak ada server, database, API, atau CLI produksi. Perubahan resource disimpan selama sesi tab dan dapat direset melalui Settings.
