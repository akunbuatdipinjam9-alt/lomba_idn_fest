Networking

Rancang koneksi privat antarresource.

PROTOTYPE DOCUMENTATION

Overview

Pilih Networks → Create network. Isi nama, pilih region, lalu pilih salah satu subnet 10.42.0.0/24 hingga 10.44.0.0/24. Subnet yang sama tidak dapat dibuat dua kali dalam satu region. Network map menampilkan route antarregion dengan latensi contoh; demo ping tidak mengirim paket jaringan.

Command reference

skyforge networks list

Yang perlu diketahui

Seluruh tindakan pada prototype berjalan lokal di browser. Tidak ada server, database, API, atau CLI produksi. Perubahan resource disimpan selama sesi tab dan dapat direset melalui Settings.
