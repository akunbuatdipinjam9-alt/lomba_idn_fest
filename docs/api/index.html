Overview

Buka API Keys → Create demo key, lalu isi nama dan pilih scope Read only atau Read & write. Token diawali demo_not_valid_ dan hanya dapat digunakan sebagai data contoh. Copy demo token menyalin token; Revoke menghapusnya setelah konfirmasi. Endpoint di bawah memakai domain .example dan tidak dapat dipanggil.

Command reference

GET https://api.skyforge.example/v1/instances
Authorization: Bearer DEMO_NOT_A_REAL_KEY

Yang perlu diketahui

Seluruh tindakan pada prototype berjalan lokal di browser. Tidak ada server, database, API, atau CLI produksi. Perubahan resource disimpan selama sesi tab dan dapat direset melalui Settings.
