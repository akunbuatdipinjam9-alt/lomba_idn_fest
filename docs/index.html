Quick Start

Dari nol ke instance demo pertama.

PROTOTYPE DOCUMENTATION

1. Buka workspace

Login hanya menyiapkan sesi browser. Buka Compute instances dan pilih Create instance. Isi nama unik, region, image Linux, dan ukuran resource. Setelah Deploy instance dipilih, status menampilkan Provisioning selama simulasi berlangsung, lalu berubah menjadi Running. Perubahan dicatat pada Activity log.

2. Jalankan deployment

skyforge deploy --name web-demo --region jakarta

Yang perlu diketahui

Seluruh tindakan pada prototype berjalan lokal di browser. Tidak ada server, database, API, atau CLI produksi. Perubahan resource disimpan selama sesi tab dan dapat direset melalui Settings.
